오늘의 집중·기억 컨디션을 게임으로 가볍게 확인한다

수면 부족이나 피로로 “오늘 유난히 멍하다”고 느낄 때, 로그인 없이 짧은 게임과 3분 집중 측정을 수행하고 내 이전 기록과 비교해 보는 독립 웹 서비스입니다. 진단이나 정상·비정상 판정이 아니라, 오늘의 자기 상태를 이해하는 참고 도구입니다.

3분 집중 측정

숫자가 나타나면 화면을 눌러요. 조용한 곳에서 이 창만 열어 두세요.

측정 시작

가입 없음 · 동의 전 저장 없음

문제

주관적인 피로감만으로는 오늘의 집중 상태를 구체적으로 설명하기 어렵습니다.

대상

수면과 피로에 따라 업무 집중력이 달라진다고 느끼는 성인입니다.

해결

7개 게임형 워밍업과 별도의 3분 집중 측정을 한 링크에 제공합니다.

가치

남과 비교하지 않고 같은 방식으로 측정한 내 기록의 변화만 확인합니다.

01 · 기획 배경

“오늘 왜 이렇게 멍하지?”를 확인할 간단한 방법이 부족하다

막연한 느낌을 기록 가능한 경험으로 바꾸되, 온라인 검사가 진단처럼 보이는 문제는 피합니다.

현재의 불편

  • 피곤하다는 느낌 외에는 오늘 상태를 설명할 근거가 없습니다.
  • 한 번의 점수는 기기·환경·연습 효과 때문에 해석하기 어렵습니다.
  • 정상·비정상처럼 단정하는 온라인 테스트는 불필요한 불안을 만들 수 있습니다.
→

우리가 만드는 변화

  • 게임으로 진입 장벽을 낮추고 짧게 반복합니다.
  • 측정 방식과 한계를 결과 옆에서 함께 설명합니다.
  • 또래 평균이 아니라 같은 방식으로 쌓은 내 기록과 비교합니다.
02 · 핵심 대상

첫 MVP는 한 사람의 한 장면에 집중한다

학생·환자·전문가를 한꺼번에 잡지 않고, 스스로 오늘 업무 준비 상태를 확인하려는 성인부터 시작합니다.

첫 번째 사용자

수면 부족이나 피로를 느낀 직장인·성인 학습자

중요한 업무나 학습을 시작하기 전, 오늘의 집중·기억 컨디션을 빠르게 확인하고 싶은 사람

“어제 잠을 설쳤는데 지금 바로 중요한 일을 시작해도 될까? 느낌 말고 내 최근 기록과 비교해 보고 싶다.”
03 · 사용자 여정

한 링크에서 이해하고, 해보고, 내 변화까지 확인한다

가입과 설문을 앞에 두지 않습니다. 설명은 필요한 순간에 짧게 보여 주고, 결과 뒤에 다음 행동을 연결합니다.

1

링크 열기

로그인 없이 목적과 비진단 원칙을 확인합니다.

2

게임 워밍업

7개 짧은 과제로 여러 인지 활동을 경험합니다.

3

3분 집중 측정

언제 나타날지 모르는 자극에 반응합니다.

4

결과 이해

이번 값, 읽는 방향, 비교 범위, 한계를 함께 봅니다.

5

내 변화 비교

저장에 동의한 경우에만 같은 기기의 기록과 비교합니다.

04 · MVP 기능

7개 게임은 워밍업, 기준선은 별도의 3분 측정으로 분리한다

각 게임이 무엇을 사용하는지 설명하지만, 특정 인지 능력이 정상인지 판단하는 점수로 바꾸지 않습니다.

순서 게임 사용하는 활동 MVP에서 보여 줄 결과
1 이야기 기억하기 읽은 내용을 잠깐 붙잡아 두기 최초 제출 기준 정답 수
2 반응속도 신호를 보고 빠르게 반응하기 평균 반응시간·이른 누름
3 숫자 뒤집기 숫자를 기억해 역순으로 바꾸기 완료한 최대 자릿수
4 색깔 단어 자동으로 떠오르는 답을 억제하기 정확도·평균 반응시간
5 이야기 다시 퀴즈 시간이 지난 뒤 내용 떠올리기 지연 정답 수·유지율
6 패턴 매칭 모양을 보고 빠르게 비교하기 정확도·평균 반응시간
7 별똥별 잡기 기다리며 신호에 주의하기 평균 반응시간·놓침 수
별도 3분 집중 측정 일정 시간 동안 반응 유지하기 ✓ 내 기준선에 사용
05 · 화면 구조

화면은 플레이·나의 변화·게임 안내 세 갈래로 단순화한다

진행 중에는 탭을 숨겨 집중을 돕고, 한 화면에는 다음 행동 하나만 강조합니다.

화면 1플레이

오늘 바로 시작

2 / 7

난이도를 고르고 게임을 시작하거나, 별도의 3분 집중 측정으로 바로 이동합니다.

화면 2나의 변화

내 기준과 비교

2 / 3회

같은 방식의 유효한 측정이 쌓였을 때만 내 기준선과의 차이를 설명합니다.

화면 3게임 안내

무엇을 보고, 무엇은 모르는지

근거 + 한계

과제의 형식, 확인하는 활동, 결과에 영향을 줄 수 있는 조건을 함께 제공합니다.

06 · 안전·개인정보

의료 판단과 개인정보 수집을 제품 가치로 착각하지 않는다

이 제품은 참고용 자기 점검 도구입니다. 결과의 불확실성과 측정 실패를 숨기지 않습니다.

! 진단하지 않음

정상·비정상, 질환 위험, 연령 백분위, 치료 권고를 제공하지 않습니다.

! 임상기기와 직접 비교하지 않음

브라우저와 기기마다 지연이 달라 절대 반응시간을 연구 장비 수치와 직접 비교하지 않습니다.

! 동의 전 저장하지 않음

이름·연락처·생년월일·환자번호를 받지 않고, 서버로 측정값을 전송하지 않습니다.

! 품질이 낮으면 비교하지 않음

탭 이탈, 자극 부족, 이른 누름 과다, 기기 지연이 있으면 재측정을 안내하고 기준선에서 제외합니다.

07 · 기술 선택

기술 이름보다 선택 이유를 먼저 설명한다

첫 MVP는 계정·서버·데이터베이스 없이도 핵심 가설을 검증할 수 있는 가장 작은 구조를 택합니다.

React + TypeScript

7개 게임의 순서·난이도·결과 상태를 명확히 나누고, 잘못된 데이터 조합을 개발 단계에서 줄이기 위해 사용합니다.

브라우저 안에서 실행

첫 MVP는 서버 호출 없이 게임과 결과 계산을 끝내 개인정보 노출 경로와 운영비를 함께 줄입니다.

동의 후 로컬 저장

회원가입 없이 내 기준선을 만들되, 사용자가 원할 때 이 기기에서 즉시 모두 지울 수 있게 합니다.

Vercel 정적 배포

별도 서버를 운영하지 않고도 모바일·PC에서 같은 URL을 열어 MVP를 빠르게 테스트하기 위해 사용합니다.

08 · 성공 기준

완성도보다 “사용자가 이해하고 끝까지 해보는가”를 먼저 검증한다

아래 수치는 현재 성과가 아니라 MVP 사용자 테스트에서 확인할 목표입니다.

첫 사용 성공 10명 중 8명 이상

별도 설명 없이 게임 또는 3분 측정을 시작하고 결과 화면까지 도달합니다.

결과 이해 10명 중 8명 이상

“진단이 아니라 내 기록과 비교하는 참고값”이라고 자신의 말로 설명합니다.

개인정보 경계 금지 정보 수집 0건

이름·연락처·생년월일·환자번호 입력과 측정값 서버 전송이 없습니다.

기술 품질 핵심 오류 0건

390px·768px·1440px에서 가로 잘림이 없고, 키보드 사용과 측정 품질 차단이 작동합니다.

09 · 실행 계획

2주 안에 작동하는 MVP와 사용자 피드백을 남긴다

첫 주에는 핵심 경험을 만들고, 둘째 주에는 반복 비교와 안전·접근성을 검증합니다.

1주차 · 핵심 경험

게임을 시작해 결과까지 도달

  • 7개 워밍업 게임과 난이도
  • 문제별 즉시 피드백
  • 결과의 의미와 한계 설명
  • 모바일·PC 기본 화면 검증
2주차 · 반복 비교

3분 측정과 내 기준선 연결

  • 연습과 본 측정 분리
  • 측정 품질 실패 차단
  • 동의 후 요약값 로컬 저장
  • 10명 사용성 테스트와 수정

한 문장으로 정리하면

인지 컨디션 체크는 피곤한 날의 막연한 느낌을 게임과 반복 기록으로 이해하도록 돕되, 의료 진단·타인 비교·불필요한 개인정보 수집은 하지 않는 웹 서비스입니다.
