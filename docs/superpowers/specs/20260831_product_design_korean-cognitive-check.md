# 한글 인지 컨디션 체크 독립 앱 설계

## 목적

기존 `ksleep-app` 안의 인지검사 경험을 독립된 한글 웹앱으로 제공함. 사용자는 로그인 없이 링크를 열어 7개 활동을 순서대로 완료하고, 같은 화면에서 결과를 확인할 수 있음.

## 승인된 범위

- 이야기 기억하기, 반응속도, 숫자 뒤집기, 색깔 단어, 이야기 다시 퀴즈, 패턴 매칭, 별똥별 잡기 등 7개 활동을 제공함.
- 새 비공개 GitHub 저장소 `Sylvie0810/ksleep-care-cognitive-check`에서만 구현함.
- `ksleep-app` 코드, API, DB, 인증, 쿠키와 완전히 분리함.
- 결과는 실행 중 브라우저 메모리에만 유지하며 서버, `localStorage`, `sessionStorage`, 쿠키에 저장하지 않음.
- 모바일 390px, 태블릿 768px, 데스크톱 1440px에서 사용할 수 있어야 함.
- Vercel Production에 배포하고 시작 화면부터 결과 화면, 다시 시작까지 실제 브라우저로 확인함.

## 사용자 흐름

1. 첫 화면에서 목적, 7개 활동, 예상 소요 시간, 비진단 안내를 확인함.
2. `검사 시작` 버튼을 누름.
3. 각 활동 전에 한 문장 설명을 읽고 `준비됐어요`를 누름.
4. 활동을 완료하면 다음 활동으로 자동 이동함.
5. 7개 활동 완료 후 기억, 반응, 작업기억, 집중, 판단 전환, 주의 결과를 쉬운 말로 확인함.
6. `처음부터 다시 하기`로 모든 브라우저 메모리 상태를 비우고 첫 화면으로 돌아감.

## 7개 활동

| 순서 | 화면 이름 | 사용자 행동 | 결과값 |
|---|---|---|---|
| 1 | 이야기 기억하기 | 짧은 이야기를 읽은 뒤 4개 질문에 답함 | 즉시 정답 수 |
| 2 | 반응속도 | 나타난 원을 6번 누름 | 평균 반응시간, 성공 수 |
| 3 | 숫자 뒤집기 | 보인 숫자를 거꾸로 입력함 | 최대 자릿수, 정답 수 |
| 4 | 색깔 단어 | 글자 뜻이 아니라 글자색을 8번 고름 | 정확도, 평균 반응시간 |
| 5 | 이야기 다시 퀴즈 | 앞에서 읽은 이야기의 4개 질문에 다시 답함 | 지연 정답 수, 기억 유지율 |
| 6 | 패턴 매칭 | 기준 모양과 같은 선택지를 6번 고름 | 정확도, 평균 반응시간 |
| 7 | 별똥별 잡기 | 무작위 간격 뒤 나타난 별을 6번 누름 | 평균 반응시간, 놓침 수 |

## 구조

- React 19 + TypeScript + Vite 정적 앱으로 구성함.
- `src/domain/`은 검사 순서, 점수 계산, 타입처럼 화면과 분리된 순수 로직을 소유함.
- `src/games/`는 각 활동의 화면과 입력만 담당함.
- `src/App.tsx`는 `intro -> transition -> game -> report` 상태를 조정함.
- 외부 API 호출 라이브러리와 백엔드 코드를 두지 않음.
- Pretendard Variable은 패키지에서 빌드 산출물에 포함해 자체 호스팅함.

## 디자인과 접근성

- 환자용 표면으로 분류하고 K-Sleep `brand` 색상 `#0059B8`을 유일한 강조색으로 사용함.
- 새 프로젝트 보정값인 `dim #727270`, `warn #906A2D`, `ok #4E7C59`를 사용함.
- 화면당 주 행동은 하나만 둠. 최소 터치 영역은 44px로 함.
- 색만으로 상태를 표현하지 않고 아이콘과 텍스트를 함께 표시함.
- 한글에는 `word-break: keep-all`과 `overflow-wrap: break-word`를 적용함.
- 숫자 결과에는 tabular 숫자를 사용함.
- 동작 감소 설정을 존중하며 250ms를 넘는 장식 애니메이션을 두지 않음.
- 검사 중 키보드 사용, 명확한 포커스 표시, 상태 안내용 `aria-live`를 지원함.

## 점수와 의료 안전 경계

- 결과는 이번 실행의 수행값만 보여줌.
- 임상 진단명, 질환 위험도, 치료 권고, 정상/비정상 판정을 표시하지 않음.
- 모든 결과 화면에 `의료 진단이 아닌 오늘의 컨디션 참고용`임을 표시함.
- 실환자 정보, 이름, 연락처, 생년월일을 입력받지 않음.

## 오류와 중단

- 활동 중 `처음으로`를 누르면 확인 후 현재 실행 상태를 비우고 첫 화면으로 돌아감.
- 타이머는 컴포넌트가 사라질 때 모두 정리함.
- 잘못된 입력은 쉬운 안내와 다시 시도 동작을 제공함.
- 네트워크가 없어도 최초 로딩 이후 모든 활동이 동작함.

## 완료 기준

- 7개 활동과 결과, 다시 시작 흐름이 자동 테스트에서 통과함.
- TypeScript 검사, 단위·통합 테스트, Production 빌드가 모두 성공함.
- 디자인 토큰 검증기가 대비와 사용 역할을 통과함.
- Production URL이 HTTP 200을 반환함.
- Production 화면을 390px, 768px, 1440px에서 확인하고 가로 넘침이 없어야 함.
- 실제 브라우저에서 7개 활동을 끝까지 완료해 결과 화면과 재시작을 확인함.
- 브라우저 저장소와 쿠키가 비어 있고 앱이 POST/PUT/PATCH/DELETE 요청을 만들지 않아야 함.
