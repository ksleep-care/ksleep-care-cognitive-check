## 0. 2026-09-01 개정에서 달라진 것

| 항목 | 이전 | 지금 | 이유 |
|---|---|---|---|

| 피드백 | 마지막 결과 화면에서만 | 문제마다 즉시 정오답 + 정답 + 한 줄 설명 | 매 문제 결과를 바로 알 수 있어야 함 |

| 시각 | beige 배경 + 흰 카드 | 어두운 게임 표면 + 목적 있는 3D·모션 | K-Sleep 앱 복제형 UI 탈피 |

## 1. 목적

로그인 없이 링크만 열어 오늘의 인지 컨디션을 스스로 확인하는 K-Sleep Care 독립 웹앱.
`ksleep-app`과 코드·API·DB·인증·쿠키를 공유하지 않는다.

## 2. 정보 구조

하단 탭 4개. **K-Sleep 앱의 `홈·리포트·기록·챗봇·수면팁` 5탭을 복사하지 않는다.**

| 탭 | 담는 것 |
|---|---|
| 홈 | 오늘 할 **한 가지** 주 행동(3분 측정) + 기준선 진행 + 워밍업 진입 |
| 플레이 | 레벨 1~4 선택, 게임 7개 세션, 별도 3분 측정 |
| 나의 변화 | 저장 동의, 기준선 진행 n/3, 최근 기록, 모두 삭제 |
| 게임 안내 | 각 과제가 무엇을 보는지와 **한계** |

세션과 3분 측정을 진행하는 동안에는 하단 탭을 숨긴다. 방해와 이탈을 막는다.

## 3. 게임 7개와 레벨

| 순서 | 이름 | 결과값 | 레벨 영향 |
|---|---|---|---|
| 1 | 이야기 기억하기 | 즉시 정답 수 | 문제 수 4/5/6/7 · **읽기 제한 25/22/20/18초** |
| 2 | 반응속도 | 평균 ms, 성공 수, 너무 이른 누름 수 | 없음 (고정) |
| 3 | 숫자 뒤집기 | 최대 자릿수, 정답 수 | 자릿수 3~4 / 4~5 / 5~6 / 6~7 |
| 4 | 색깔 단어 | 정확도, 평균 ms | 문제 수 6/8/10/12 |
| 5 | 이야기 다시 퀴즈 | 지연 정답 수, 유지율 | 문제 수 4/5/6/7 |
| 6 | 패턴 매칭 | 정확도, 평균 ms | 문제 수·기호 수 |
| 7 | 별똥별 잡기 | 평균 ms, 놓침 수 | 없음 (고정) |

**레벨은 3분 PVT에 절대 영향을 주지 않는다.** 레벨이 다른 결과를 같은 기준선으로 비교하지 않는다.

이야기를 읽는 시간은 레벨별로 제한한다. 읽은 시간이 사람마다 다르면 기억 점수를
자기 기록끼리도 비교할 수 없기 때문이다. 남은 시간을 초와 막대로 보여주고,
0초가 되면 이야기를 감추고 첫 질문으로 자동으로 넘어간다. 먼저 다 읽으면
`다 읽었어요`로 미리 넘어갈 수 있다. `이야기 다시 퀴즈`에는 읽기 화면이 없으므로 타이머도 없다.

숫자 뒤집기는 선택 버튼이 아니라 직접 입력이다. 모바일 숫자 키패드(`inputMode="numeric"`),
자동완성·자동수정·맞춤법 끄기, Enter 제출, 숫자 아닌 문자 차단, 명확한 포커스를 제공한다.

## 4. 문제별 즉시 피드백

이야기·숫자·색깔·패턴은 제출할 때마다 `맞았어요` / `아쉬워요`를 먼저 보여주고,
틀렸으면 정답과 한 줄 설명을 준 뒤 **사용자가** 다음 문제로 넘어간다.

**점수는 항상 최초 제출로 확정된다.** 정답을 본 뒤 다시 누른 값은 점수에 섞지 않는다.
학습 피드백과 측정값을 분리하기 위한 계약이며 테스트로 고정한다.

반응속도와 별똥별은 시행마다 ms 또는 `너무 일찍 눌렀어요` / `놓쳤어요`를 즉시 알려준다.
**3분 PVT는 hit·lapse·false start의 짧은 중립 문구만 준다.** 축하 particle, 흔들림, 화면 이동을 쓰지 않는다.

## 5. 3분 PVT 측정 계약

정본은 `src/domain/pvt.ts`의 상수 하나뿐이다. 문서와 코드에 값을 두 번 적지 않는다.

근거: Basner M, Mollicone D, Dinges DF, *Validity and sensitivity of a brief psychomotor
vigilance test (PVT-B) to total and partial sleep deprivation*, Acta Astronautica 69 (2011)
949–959. 원문 Material and methods를 직접 확인함.

- 측정 3분. 연습 구간은 점수에 넣지 않는다.
- 자극 간격 2~4초 (논문이 355ms 기준을 보정한 조건).
- 반응시간 100ms 미만 = false start (errors of commission).
- 30초 무응답 = lapse, 반응시간 30000ms로 기록.
- lapse 기준 **≥ 355ms**. **10분 PVT의 500ms 기준과 어디에서도 섞지 않는다.**
- 수행 점수 = 100% − (lapse + false start) / (유효자극 + false start).

지표: 반응시간 중앙값, lapse 수, false start 수, 변동성(IQR), 후반부 변화, 수행 점수,
가장 빠른/느린 10%, 유효·무효 사유.

### 5.1 논문과 다른 점 — 화면에 반드시 적는다

논문은 전용 측정기기 PVT-192(LED 표시 + 물리 버튼)를 썼다. 이 앱은 브라우저다.
화면 표시 지연과 입력 지연이 달라서 **절대 반응시간(ms)을 논문 수치와 직접 비교하지 않는다.**
355ms는 lapse를 세는 규칙으로만 쓴다.

3분 PVT를 10분 PVT 기준으로 해석하면 안 되는 근거: PMC8885985 —
"the PVT-3 is not interchangeable with the PVT-10".

### 5.2 측정 품질

`performance.now()`를 쓴다. 화면 표시 지연을 완전히 제거했다고 주장하지 않는다.
아래 중 하나라도 걸리면 `다시 측정 권장`으로 표시하고 **기준선에 넣지 않는다.**

| 사유 | 판정 |
|---|---|
| `tooFewStimuli` | 유효 자극 30개 미만 |
| `tabHidden` | 측정 구간에 탭이 백그라운드로 감 |
| `excessFalseStarts` | false start 비율 20% 초과 |
| `timingDrift` | 자극 표시 지연 중앙값 80ms 초과 |

## 6. 결과 — 두 개 층

### 6.1 연구 참고 층 (PVT 지표에만)

같은 프로토콜에서 반응시간·lapse·변동성이 일반적으로 어떻게 움직이는지만 출처와 함께 적는다.
`연구 참고`와 `의료 기준이 아님`을 항상 같이 보여준다.

**검증된 연령별 규준이 없으므로 동년배 percentile, 정상·주의·위험, ADHD 점수를 만들지 않는다.**

### 6.2 개인 기준선 층

명시적으로 저장에 동의한 사용자의 **이전 유효 PVT 결과만** 비교한다.

- 이전 유효 결과 3회 미만 → `기준 만드는 중 n/3`
- 3회 이상 → 최근 5회의 중앙값과 이번 값의 차이를 `몇 ms 빠름/느림`, `lapse 몇 회 적음/많음`
- 좋음·나쁨, 치료 효과로 단정하지 않는다.
- 이번 결과는 **자기 자신을 기준선에 넣기 전에** 비교한다.
- 동일 브라우저·동일 프로토콜 버전에서만 비교한다. 버전이 바뀌면 새 기준선을 시작한다.

### 6.3 게임 결과

`게임 기록`으로만 표시한다. 임상검사 규준을 상속하지 않는다.
`작업기억을 활용하는 게임`이라고 쓰되 `작업기억 정상`이라고 쓰지 않는다.
비교 범위는 `같은 레벨에서 한 내 기록끼리만`이다.

모든 결과 카드는 **무엇을 본 과제인지 · 이번 값 · 읽는 방향 · 비교 가능한 범위 · 한계**를 함께 준다.

## 7. 개인정보와 로컬 저장

- 기본은 **꺼짐**. 사용자가 `이 기기에 나의 변화 저장`을 켠 뒤에만 저장한다.
  동의 전에는 브라우저 영구 저장소가 비어 있다.
- 저장 허용 필드는 정확히 6개다: `protocol`, `completedAt`, `medianRtMs`, `lapses`,
  `falseStarts`, `performanceScore`. schema 테스트가 그 외 필드를 전부 잘라낸다.
- 이름·연락처·생년월일·환자번호·진단명·치료순응도·이야기 답안·숫자 입력값·전체 raw trial은
  저장하지 않는다.
- 서버 전송·계정·쿠키·외부 analytics는 없다.
- `내 기록 모두 삭제`를 제공하고, 삭제 즉시 UI와 저장소에서 함께 사라진다.
- `이 기기에만 저장됨`과 `같은 기기를 쓰는 다른 사람도 볼 수 있음`을 동의 화면과 변화 화면에 함께 적는다.
- 깨진 값이나 모르는 schema 버전은 억지로 읽지 않고 지운다.

## 8. 디자인과 모션

상세 정본은 root `DESIGN.md`. 요약만 적는다.

- 어두운 게임 표면. violet / cyan / coral / lime 4색. K-Sleep `#0059B8`은 로고 마크에만.
- 3D는 목적이 있을 때만: 타일 tilt·누름 깊이, 레벨 선택, 진행 트랙, 결과 카드 층.
- 모션은 화면 전환·진행·정답 피드백·완료에만.
- **PVT 측정 화면에는 tilt·particle·parallax·spring 이동·동적 배경을 넣지 않는다.**
  타깃 위치·크기·표시 방식이 고정된다. 배경 애니메이션도 정지한다(`.is-measuring`).
- `prefers-reduced-motion`에서 의미를 잃지 않는 정적 대체를 제공한다.
- 터치 영역 44px 이상, 색 외 상태 표현, `:focus-visible`, `aria-live`, `word-break: keep-all`.

## 9. 완료 기준

- `npm run check && npm test && npm run build` 모두 exit 0.
- 디자인 토큰 검증기 위반 0건.
- 390px·768px·1440px에서 가로 넘침 없음.
- 실제 브라우저에서 홈 → 레벨 → 게임 7개 → 문제별 정오답 → 3분 PVT → 결과 → 저장 동의 →
  나의 변화 → 삭제 → 다시 시작이 동작.
- 탭 백그라운드 이탈과 false start를 만들어 품질 경고가 뜨는 것을 확인.
- Production HTTP 200 + 배포된 화면에서 위 흐름과 새 문구 확인.

## 10. 이번 범위가 아닌 것

`ksleep-app` 연결, 환자 계정, 치료 순응도 연동, 의료진 화면, 서버 저장,
연령별 임상 규준 개발, ADHD 선별·진단, 진료 권고, 실제 환자 데이터, PR·merge.
