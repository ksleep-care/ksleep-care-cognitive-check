# 인지 컨디션 체크

로그인 없이 기억·숫자·색깔·패턴·반응 게임 7개를 하는 독립 웹앱.
연구 과제의 핵심 원리를 참고했지만 정식 검사, ADHD 선별, 진단, 치료 도구가 아니다.

첫 화면은 플레이이고 루키~마스터를 선택한 뒤 코스를 시작한다.
별도 3분 측정과 기준선 생성은 앱에서 제외했다. 과거 도메인 코드는 회귀 테스트용으로 보존되며 실행 경로는 없다.
운영 URL: https://ksleep-care-cognitive-check.vercel.app
이 문서는 변경된 소스 설명이며 운영 배포 완료를 뜻하지 않는다.

## 경계

- CareLoop/SOOMi와 코드·API·DB·인증·쿠키를 공유하지 않는다.
- 실제 환자정보·이름·연락처·생년월일·환자번호를 받지 않는다.
- 게임 결과와 답안은 메모리에만 두고 서버나 영구 저장소에 쓰지 않는다.
- 과거 저장 기록은 자동 삭제하지 않으며 게임 안내에서 본인이 확인 후 지울 수 있다.
- 화면을 새로고침하면 코스 진행이 사라진다. 다른 난이도·기기·변경 전 버전 기록을 직접 비교하지 않는다.

## 과제

이야기 → 반응속도 → 숫자 뒤집기 → 색깔 단어 → 이야기 다시 퀴즈 → 패턴 매칭 → 별똥별 잡기.

숫자는 매번 새로 생성해 한 자리씩 제시하고 수행에 따라 길어진다.
Stroop은 일치·불일치 조건을 모두 포함한다.
이야기의 첫 퀴즈에서는 정답을 공개하지 않는다. 24개 가상 사건으로 본문을 조합하며 같은 방문 안의 중복을 막는다.
재방문 이력을 저장하지 않으므로 새로고침·기기 변경까지 절대 중복 방지를 보장하지 않는다.

난이도 숫자의 정본은 `src/domain/levels.ts`다. 상세 출처·커스터마이징 경계·검증은 [게임 UX 개선](docs/ux-game-revision.md)을 따른다.

## 로컬 실행과 검증

```bash
npm run dev
npm run check && npm test && npm run build
```
